📦 ÉTAPE 1 : TÉLÉCHARGER LE ZIP
================================
1. Allez sur : https://github.com/onguiba/smart-workfore-gestion-des-employ-s
2. Cliquez "Code" → "Download ZIP"
3. Extrayez le ZIP sur votre ordinateur

🗄️ ÉTAPE 2 : CRÉER LA BASE DE DONNÉES
======================================
1. Connectez-vous à hPanel Hostinger
2. Allez dans "Bases de données MySQL"
3. Cliquez "Créer une nouvelle base de données"
4. NOTEZ les informations (automatiques) :
   - Nom BDD : u954610625_db_OhzWYKBo
   - Utilisateur : u954610625_usr_OhzWYKBo
   - Mot de passe : S@SuF-db

📋 ÉTAPE 3 : IMPORTER LES TABLES SQL
====================================
1. Dans hPanel, cliquez "phpMyAdmin"
2. Sélectionnez votre base de données (dans le menu gauche)
3. Cliquez sur l'onglet "SQL" en haut
4. Ouvrez le fichier "database.sql" du ZIP
5. Copiez TOUT son contenu
6. Collez dans phpMyAdmin et cliquez "Exécuter"
7. ✅ Les tables sont créées !

⚙️ ÉTAPE 4 : CONFIGURER LA CONNEXION
====================================
1. Ouvrez le fichier "api/config.php" (avec Notepad++)
2. Remplacez les valeurs ligne 5-8 :
   
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'u954610625_db_OhzWYKBo');  ← VOTRE BASE
   define('DB_USER', 'u954610625_usr_OhzWYKBo'); ← VOTRE USER
   define('DB_PASS', 'S@SuF-db');                ← VOTRE PASS

3. Sauvegardez le fichier

📤 ÉTAPE 5 : UPLOADER LES FICHIERS
==================================
1. Dans hPanel, cliquez "Gestionnaire de fichiers"
2. Allez dans le dossier "public_html"
3. SUPPRIMEZ tout ce qui s'y trouve (sauf .htaccess si présent)
4. Uploadez TOUS les fichiers du projet :
   ✅ Dossier "frontend" (complet)
   ✅ Dossier "api" (complet)
   ✅ Fichier "index.php"
   ✅ Fichier ".htaccess"

🎉 ÉTAPE 6 : TESTER
==================
1. Ouvrez : https://votredomaine.com
2. Vous devriez voir la page d'accueil TSA
3. Testez l'inscription : https://votredomaine.com/frontend/register.html

   → Vérifiez que .htaccess est uploadé

   → Vérifiez que le dossier "api/" est bien uploadé
