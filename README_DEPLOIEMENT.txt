Ce projet fonctionne en **100% Node.js pur** avec une **Base de Données JSON autonome**.
- ❌ ZÉRO PHP
- ❌ ZÉRO MySQL
- ❌ ZÉRO configuration compliquée
- ✅ Compatible avec les hébergements Hostinger supportant Node.js !

------------------------------------------------------------------------------
COMMENT DÉPLOYER SUR HOSTINGER :
------------------------------------------------------------------------------

1. TÉLÉCHARGER LE ZIP :
   - Sur votre dépôt GitHub, cliquez sur [ <> Code ] > [ Download ZIP ]
     ou téléchargez directement : smart-workforce-hostinger-deploy.zip

2. DÉPOSER SUR HOSTINGER :
   - Rendez-vous sur votre espace Hostinger (hPanel).
   - Accédez au "Gestionnaire de fichiers" > ouvrez le dossier "public_html".
   - Déposez-y le fichier ZIP et faites un Clic Droit > "Extraire".

3. ACTIVATION NODE.JS HOSTINGER :
   - Dans hPanel > "Applications Node.js" (ou "Configuration Node.js") :
     • Version Node.js : 18.x ou 20.x
     • Fichier d'application : app.js
     • Mode de démarrage : production
   - Cliquez sur "Démarrer" / "Start".

4. ACCÉDER AU SITE :
   - Ouvrez votre nom de domaine dans votre navigateur :
     Toutes les fonctionnalités (Pointage Face ID, Dashboard, Portail) fonctionnent
     immédiatement sans aucune base de données MySQL à créer !
