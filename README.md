## ? DÉPLOIEMENT ULTRA-RAPIDE SUR HOSTINGER (1 SEULE ÉTAPE)

Cette archive est **directement formatée pour public_html**. Vous n'avez aucun dossier à déplacer ni aucun fichier à réorganiser !

1. **Téléchargez le ZIP** depuis GitHub :
   - Cliquez sur **<> Code** > **Download ZIP**
   ou téléchargez directement le fichier pré-packagé :
   - [smart-workforce-hostinger-deploy.zip](https://github.com/onguiba/smart-workfore-gestion-des-employ-s/raw/main/smart-workforce-hostinger-deploy.zip)

2. **Uploadez dans Hostinger** :
   - Ouvrez votre panneau **Hostinger (hPanel)** > **Gestionnaire de fichiers** > dossier **public_html**.
   - Déposez le ZIP dans public_html.
   - Faites un **Clic droit sur le ZIP** > **Extraire**.

3. **C'est tout !**
   - Ouvrez votre domaine : tous vos fichiers (home.html, ttendance.html, dashboard.html, etc.) sont directement actifs à la racine.
   - Les APIs /api/... sont automatiquement prises en charge par le serveur Apache via .htaccess.
