# 🌐 TSA SmartWorkforce AI™ — Système Intelligent de Gestion RH

Application web complète de gestion RH et de pointage biométrique (Face ID & manuel) construite en **100% Node.js pur avec Base de Données JSON autonome**.

## 🚀 Caractéristiques :
- ❌ **Aucun PHP requis**
- ❌ **Aucun serveur MySQL requis**
- ⚡ **Base de Données JSON intégrée** (ackend/data/database.json) avec persistance automatique.
- 🕒 **Calcul automatique des temps** : Arrivée, Départ, Durée de travail journalière (ex: 07:00 à 18:00 = 11h 00min).
- 📱 **Interface complète** : Dashboard RH en direct, Portail Collaborateur, Pointage Face ID, Congés, Paie, Missions, etc.

1. Téléchargez le ZIP : [smart-workforce-hostinger-deploy.zip](https://github.com/onguiba/smart-workfore-gestion-des-employ-s/raw/main/smart-workforce-hostinger-deploy.zip) ou via **Code > Download ZIP**.
2. Dans Hostinger **Gestionnaire de fichiers** (public_html), déposez et extrayez le ZIP.
3. Configurez l'application Node.js dans Hostinger avec **pp.js** comme fichier de démarrage.
